# 🧳 Travel Booking System

A database project for managing travel packages, customer bookings, and analyzing popular destinations.

## 📌 Features
- **Packages Management:** Store travel destinations, duration, and pricing.
- **Bookings Tracking:** Record customer details, package IDs, and travel dates.
- **Data Analytics:** Query to analyze total bookings per destination.

- Database & Table Creation

- Analytical Join Queries
